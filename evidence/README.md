# Evidence

Runtime proof for this repository lives here.

## Required metadata

Each evidence document must include:

- date;
- platform profile;
- Kubernetes/OpenShift version;
- component version;
- namespace/project;
- commands;
- expected result;
- observed result;
- conclusion;
- limitations.

## Template

```markdown
# Evidence — <test>

Date:
Platform:
Cluster version:
Component:
Component version:

## Objective

## Preconditions

## Commands

## Expected

## Observed

## Result

PASS / FAIL / PARTIAL

## Limitations
```

## Rule

Evidence from another repository is not copied here as proof. It may be referenced as prior work only.
